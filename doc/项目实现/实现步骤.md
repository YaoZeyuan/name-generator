# 实现步骤

目前看需要这么几步:

1.  编写脚本，根据原始数据生成候选名数据库
    1.  制定候选名字段
    2.  制定评分规则
2.  编订筛选规则，根据规范生成筛选条件
3.  编写脚本，根据筛选条件，给出候选名
4.  精细筛选，例如猜你喜欢。根据评分，对候选名进行排序
