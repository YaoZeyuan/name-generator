# 实现步骤

目前看需要这么几步:

1.  编写脚本，根据原始数据生成候选名数据库
    1.  制定候选名字段
        1.  需要定义候选名的数据结构，以便后续的评分和筛选。
        2.  考虑到后续可能的扩展，需要预留一些字段，例如原始数据来源、评分结果等。
    2.  制定评分规则
2.  编订筛选规则，根据规范生成筛选条件
3.  编写脚本，根据筛选条件，给出候选名
4.  精细筛选，例如猜你喜欢。根据评分，对候选名进行排序


# 具体实现

## 评分规则

> 先整理具体评分项，不看是否可实现

| 层级     | 类型     | 示例                         |
| -------- | -------- | ---------------------------- |
| 基础规则 | 硬性过滤 | 生僻字、谐音歧义、重名率过高 |
| 音律规则 | 发音     | 平仄、声母重复               |
| 文化规则 | 来源质量 | 是否有典故                   |
| 语义规则 | 含义质量 | 是否正向含义                 |
| 结构规则 | 字形结构 | 左右对称、笔画均衡           |
