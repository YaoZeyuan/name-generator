1.  财富论/五道口 等数据集中，不应区分精选集和集思录这个概念，而是应当允许按出现频率进行筛选。预期是一个进度条，两边可以调整，按出现频率分位值控制候选池的范围。默认是将出现频率按从高到低排序，从1%~100%之间可选。其中前1%完全不可选(避免选中无意义的词)
2.  为方便计算，可以按每1%为一个分组，这样只要分100组就可以了
3.  不应该展示「未发现明显语义风险」，因为就没进行过语义分析
4.  登科录、古人云应提供该候选名的来源，可以提供前5个，方便查阅。提供一个按钮，点击后可以跳转到「https://www.baidu.com/s?wd=${来源人名}」页面，方便用户了解
5.  指定字要加说明，说明可以填多个。默认为`斌波超丹徳芳凤刚桂国涵航豪浩皓和红华辉佳建杰静娟军俊兰磊丽玲`。
    除非勾选按钮「没想好，随便看看」，否则指定字中至少要有一个，以避免乱选
